# 🏦 PyBank - Console Banking Application

A simple and robust console-based banking application built in Python. This project demonstrates core programming concepts, data structure manipulation, and basic financial logic.

## 🚀 Features
- **Account Management:** Balance checking and secure tracking.
- **Transactions:** Cash deposits, withdrawals, and financial calculations.
- **Modern Tooling:** Managed via `uv` for lightning-fast dependency handling.

## 🛠️ Tech Stack & Tools
- **Language:** Python 3.12.7
- **Package Manager:** uv
- **Environment:** Virtual environment configuration via `.gitignore`

## 🌍 Language Note
The user interface and text prompts in this application are in **Ukrainian**, while the source code logic, variable names, and architecture follow global **English** IT standards.

## 💻 How to run
1. Install `uv` if you haven't already.
2. Clone the repository: `git clone https://github.com/Legin989/banking.git`
3. Run the application: `uv run main.py`
